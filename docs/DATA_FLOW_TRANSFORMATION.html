Stage 1

User Prompt

INPUT
WebSocket Gateway — start_session / text_input

Raw user input: a topic string or question.

Data Structure

// WebSocket event from client { type: 'start_session', topic: string } // or { type: 'text_input', text: string }

Transformation

Gateway extracts topic or text, fetches RLPolicy from RLService, and invokes AgentService.reason(topic, policy).

Stage 2

ReasoningOutput

OUTPUT OF AgentService.reason()
AgentService — Claude decomposition

Structured knowledge decomposition: conceptual primitives, relationships, visual hints, scene contracts.

Data Structure

interface ReasoningOutput { topic: string; conceptualPrimitives: Array<{ label: string; type: DataType; // CONCEPT | DEFINITION | EXAMPLE | ANALOGY | PROCESS | RESOURCE | COUNTERPOINT content: string; narration: string; visualHint?: { suggestedEntities, layoutPattern, visualMetaphor, colorScheme }; domain?: AcademicDomain; sceneContract?: SceneContract; }>; relationships: Array<{ from, to, type: EdgeType, label }>; prerequisiteDependencies: string[]; complexityGradient: string[]; anticipatedFollowUps: string[]; }
↓
Stage 3

KnowledgeGraph

OUTPUT OF KnowledgeGraphService.buildFromReasoning()
KnowledgeGraphService — Graph construction

Nodes from conceptual primitives, edges from relationships. Layout positions computed. Visual specs assigned per node.

Data Structure

interface KnowledgeGraph { sessionId: string; rootNodeId: string; nodes: Record<string, KGNode>; edges: Record<string, KGEdge>; maxDepth: number; nodeLimit: number; createdAt, updatedAt: number; } interface KGNode { id, label, content, narration: string; type: DataType; domain?: AcademicDomain; depth: number; visual: VisualSpec; // elementType, x, y, width, height, style, animation visualHint?: VisualHint; rlRelevanceScore: number; metadata: { sceneContract? }; } interface KGEdge { id, sourceId, targetId, label: string; type: EdgeType; weight: number; }
↓
Stage 4

PresentationScene[]

OUTPUT OF PresentationPlanner.computeTraversalOrder() + composeSceneLocals()
PresentationPlanner — BFS traversal, 1 node per scene

Ordered scenes with narration, viewport, visual commands, duration estimate. Visual script generated later per scene.

Data Structure

interface PresentationScene { id: string; nodeIds, edgeIds: string[]; narration: string; focusNodeId: string; viewport: { x, y, zoom }; visualCommands: VisualCommand[]; durationEstimate: number; visualScript?: VisualScript; // Populated by pipeline illustrations?: IllustrationSpec[]; // Legacy }
↓
Stage 5a

VisualScript — Frame-Based Visual Narrative

OUTPUT OF AgentOrchestrator → VisualScriptGenerator
VisualScriptGenerator — Claude analyzeNarration → segmentsToFrames

Claude produces VisualSegment[] (JSON). Segments convert to IllustrationFrame[] with accumulative entity model. LayoutEngine + SceneCompositionService post-process.

Intermediate: VisualSegment (Claude JSON output)

// Per-segment from Claude { text, timeRangePercent: [start, end], entities: [...], description } // Entity in segment { type, label, position, color, size, animation, from, to, parent }

Data Structure: VisualScript

interface VisualScript { sceneId: string; frames: IllustrationFrame[]; totalDuration: number; entities: Record<string, VisualEntity>; } interface IllustrationFrame { id: string; startTime, endTime: number; entities: VisualEntity[]; transitions?: EntityTransition[]; narrationSegment, description: string; } interface VisualEntity { id: string; type: VisualEntityType; // Server, Pod, Arrow, Equation, Graph2D, etc. position: { x, y }; // 0-100% size: { width, height }; label?, color?, highlight?; animation?: { type, duration, delay }; sourceEntityId?, targetEntityId?; // For Arrow/DataFlow textContent?, codeLanguage?; metadata?: Record<string, any>; }

Stage 5b: PreparedScene

ScenePipelineOrchestrator runs VisualScript + TTS in parallel. Rescales VisualScript timings to match real audio duration. Compiles to StoryboardScene.

interface PreparedScene { scene: PresentationScene; // With visualScript attached storyboard?: StoryboardScene; audioData?: Uint8Array; wordTimestamps?: WordTimestamp[]; audioDurationMs?: number; status: ScenePreparationStatus; }
↓
Stage 6

StoryboardScene — Executable Agent Commands

OUTPUT OF compilePresentationScene() — VisualScriptCompiler
VisualScriptCompiler — VisualScript → AgentCommand[]

VisualScript frames become createElement, fadeIn, moveTo, fadeOut, destroyElement. VisualCommand[] (legacy) become showElement, highlight, etc. SyncMarkers bind commands to word indices.

Transformation: VisualScript → AgentCommand[]

Each frame entity: createElement (timing: frame.startTime + delay) → fadeIn (await-previous). Position changes → moveTo. Removed entities → fadeOut → destroyElement.

Data Structure

interface StoryboardScene { id, name, narration: string; agentCommands: AgentCommand[]; syncMarkers?: SyncMarker[]; viewport: ViewportState; interactiveParameters: string[]; estimatedDurationSeconds: number; } interface AgentCommand { method: string; // createElement, fadeIn, moveTo, zoomTo, panTo, etc. args: Record<string, unknown>; timing: 'immediate' | 'await-previous' | number; } interface SyncMarker { wordIndex: number; command: AgentCommand; }

WebSocket Delivery

Gateway sends scene_change with StoryboardScene, then agent_audio_meta (durationMs, wordTimestamps, visualScript), then binary audio.

↓
Stage 7

Frontend — Rendered Illustrations

sessionStore → SceneGraphPresenter → useSceneEngine → FrameRenderer
SceneExecutor executes AgentCommand[] against EnvironmentAPI

Each createElement adds SceneElement to engine. fadeIn/moveTo update element state. Dirty render cycle updates only changed elements.

Data Structure: SceneElement (Engine State)

interface SceneElement { id: string; // "sceneId:entityId" type: StageElementType; // box | circle | arrow | text | code | diagram | label | group position: Vector2; visible, opacity, zIndex; properties: { visualEntityType, label, color, width, height, ... }; }

Transformation: elementToVisualEntity

SceneElement → VisualEntity: pixel position → percentage, extract visualEntityType, label, color, size from properties.

Final: FrameRenderer → SVGLibrary

VisualEntity[] dispatched by type to 40+ SVG components (Server, Pod, Arrow, Equation, Graph2D, etc.). Each component renders SVG elements. Canvas is 1600×900.
